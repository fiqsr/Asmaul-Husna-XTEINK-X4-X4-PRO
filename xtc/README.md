# Berkas XTC Asma'ul Husna untuk Xteink X4

Folder ini memuat berkas biner `.xtc` siap pakai:

- **`Asmaul-Husna.xtc`**: 35 halaman lengkap (Cover + 33 Halaman @ 3 Asma + Halaman Penutup).

## Cara Memindahkan ke Xteink X4

1. Hubungkan perangkat **Xteink X4** Anda ke komputer menggunakan kabel USB-C atau masukkan kartu microSD perangkat ke komputer.
2. Salin berkas `Asmaul-Husna.xtc` ke dalam folder buku/komik di kartu memori Xteink X4.
3. Lepaskan koneksi secara aman (*eject*), lalu buka menu pembaca di Xteink X4 Anda.
