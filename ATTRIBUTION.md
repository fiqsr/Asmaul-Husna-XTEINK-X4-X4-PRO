# Atribusi dan Sumber Data

Proyek ini dibangun dengan merujuk dan mengintegrasikan dua karya sumber terbuka:

1. **Data Asma'ul Husna**:
   - Repositori: [haikelz/asmaul-husna-api](https://github.com/haikelz/asmaul-husna-api)
   - Pembuat: Haikel
   - Deskripsi: API dan dataset 99 Asma'ul Husna lengkap dengan nomor urut, lafal Arab, transliterasi Latin, dan terjemahan bahasa Indonesia.

2. **Spesifikasi & Format Berkas `.xtc` Xteink X4**:
   - Repositori: [andidewanto/xteink-x4-quran-indonesia](https://github.com/andidewanto/xteink-x4-quran-indonesia)
   - Pembuat: Andi Dewanto
   - Deskripsi: Standar encoder bitmap 1-bit XTG dan pembentukan kontainer berkas biner `.xtc` untuk perangkat e-paper Xteink X4 Pro.

Seluruh hak cipta atas dataset asli tetap berada pada masing-masing pemegang hak. Proyek ini tidak mengklaim kepemilikan atas lafal-lafal Asma'ul Husna maupun terjemahannya.
